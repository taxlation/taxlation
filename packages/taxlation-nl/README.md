#  Taxlation NL Package

This package contains the translation of Dutch tax regulation into code. It builds on [taxlation-core](https://pypi.org/project/taxlation-core/).

## Regulation
The taxlation package covers some regulation of the following law:
- Algemene termijnenwet (atw)
- Algemene wet bestuursrecht (awb)
- Wet op belastingen van rechtsverkeer (wbr)
